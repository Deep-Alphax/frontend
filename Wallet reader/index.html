Relevância (0–100) começa com uma sugestão automática = nº de carteiras rastreadas para o mesmo trader (mais carteiras ⇒ mais ativo) + bônus se ele pertence a um squad nomeado (Lair, Ninety, Maurits…). É só um ponto de partida — ajuste o slider no perfil com base em popularidade real, frequência de calls e volume que o trader move.

Tipo de trader (Trencher, Whale, Alpha, Rugger…) não vem preenchido — são só etiquetas disponíveis para você classificar.

Grupos / FnFs são etiquetas que você cria pra marcar quem anda junto — uma call room, uma FnF, uma cabal. Diferente do "Squad" (que vem fixo do wallets.txt), esses grupos são 100% seus.

Tudo isso (twitter, tipo, relevância, notas, foto, grupos/FnFs, carteiras adicionadas/removidas, KOLs criados/removidos) fica salvo só no seu navegador (localStorage). Use "Exportar backup" para guardar um arquivo .json de segurança.
